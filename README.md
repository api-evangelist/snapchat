# Snapchat (snapchat)
Snapchat is a multimedia messaging platform developed by Snap Inc. Their developer platform provides a suite of APIs and SDKs for advertising, AR experiences, social authentication, and creative sharing, enabling developers to integrate Snapchat's capabilities into their own applications.

## APIs

### Snapchat Ads API
The Snapchat Ads API allows developers to programmatically create, manage, and optimize advertising campaigns on the Snapchat platform. It provides endpoints for managing ad accounts, campaigns, ad squads, ads, and creatives, as well as retrieving performance metrics and audience targeting data. The API supports the full advertising lifecycle from campaign setup through reporting and optimization.

### Snapchat Conversions API
The Snapchat Conversions API (CAPI) is a structured, privacy-centric interface that allows advertisers to pass web, app, and offline conversion events directly to Snap via a server-to-server integration. It helps optimize ad campaigns, improve targeting, and measure conversions while supporting first-party custom audience population in real-time. Snap recommends using it alongside Pixel or MMP integrations for comprehensive measurement.

### Snapchat Login Kit
Snapchat Login Kit enables developers to let users sign up and log in to their apps using their Snapchat account credentials. Built on the industry standard OAuth2 framework, it removes the friction of traditional signup flows and allows users to bring their Bitmoji avatar and display name into third-party applications. Login Kit is available as an SDK for iOS, Android, and Web platforms.

**Human URL:** [https://developers.snap.com/snap-kit/creative-kit/overview](https://developers.snap.com/snap-kit/creative-kit/overview)

### Snapchat Creative Kit
Snapchat Creative Kit provides developers with advanced sharing capabilities that go beyond native share actions. It allows apps to send sticker assets for users to decorate Snaps and link to Dynamic Lenses for sharing live data like scores or weather. Creative Kit does not require the installation of any additional SDKs and is available for iOS, Android, and Web platforms.

**Human URL:** [https://developers.snap.com/snap-kit/creative-kit/overview](https://developers.snap.com/snap-kit/creative-kit/overview)

### Snapchat Bitmoji Kit
Snapchat Bitmoji Kit is a sticker picker SDK that provides deeper integration with Bitmoji avatars in third-party applications. It allows developers to embed a Bitmoji sticker picker so users can personalize their experience with their own avatar. Bitmoji Kit supports contextual stickers and can be integrated into messaging, social, and entertainment applications on iOS and Android.

**Human URL:** [https://developers.snap.com/snap-kit/creative-kit/overview](https://developers.snap.com/snap-kit/creative-kit/overview)

### Snapchat Camera Kit
Snapchat Camera Kit is a cross-platform SDK that allows developers to bring Snap's AR Lens technology into their own iOS, Android, and web applications. It supports Remote APIs for bidirectional communication between Lenses and host applications, enabling real-time data exchange including images, 3D models, and other content. Camera Kit enables developers to enrich their apps with engaging AR experiences powered by the same technology behind Snapchat's camera.

**Human URL:** [https://developers.snap.com/camera-kit/home](https://developers.snap.com/camera-kit/home)


#### Tags:

#### Properties

- [Documentation](https://developers.snap.com/camera-kit/home)

### Snapchat Lens Studio API
The Snapchat Lens Studio API provides a comprehensive scripting interface for building augmented reality Lenses on the Snapchat platform. It includes APIs for depth sensing, automated speech recognition in over 40 languages, 3D object generation via Snap3D, and a Plugins Editor API for extending Lens Studio functionality. Lens Studio serves as the primary development environment for creating AR experiences distributed through Snapchat and Camera Kit.

**Human URL:** [https://developers.snap.com/lens-studio/home](https://developers.snap.com/lens-studio/home)
